  f = dma ... chunkat(expr, expr1, a[expr2]) => ...

is transformed to be:

  id = expr;
  id1 = expr1;
  val = expr2;
  f = dma ... chunkat(id, id1, a[val]) => ...

2. normalize of buffer:

  f = dma ... => local;
  f1 = dma ... => select(...);

is transformed to be:

  f32 [...] anon_0;
  anon_1 = select(...);
  f = dma ... => anon_0;
  f1 = dma ... => anon_1;

3. future-buffer 1-1 mapping and dataof simplification:

  f0 = ... => buf0;
  f1 = ... => buf1;
  ...
  call kernel(f0.data, f1.data, ...);

The mapping is collected by traversing the statement. The code then transformed to be:

  f0 = ... => buf0;
  f1 = ... => buf1;
  ...
  call kernel(buf0, buf0, ...);

  b = select(f1.data, f2.data);
